# ShortLib

iOS-приложение для кратких пересказов книг: EPUB-файлы и веб-новеллы по ссылке на оглавление.
Пользователь выбирает детальность (3–25% от оригинала), фокус (сюжет, персонажи, мир, цитаты)
и диапазон глав.

- **iOS 16+**, Swift 5, SwiftUI + UIKit
- **MVVM + Router / Coordinator**
- Без внешних зависимостей

## Запуск

1. Откройте `ShortLib.xcodeproj` в Xcode 15 или новее (на Mac).
2. Target ShortLib → Signing & Capabilities → выберите свою команду (Team).
3. Выберите симулятор iPhone и нажмите Run (⌘R).

При первом запуске в библиотеке есть пример книги, на нём можно сразу проверить пересказ.

## Архитектура

```
AppCoordinator ── UITabBarController
 ├─ LibraryCoordinator      Библиотека → Карточка книги
 │   └─ SummaryCoordinator  Настройки (sheet) → Прогресс → Чтение
 ├─ ImportCoordinator       модально: EPUB из «Файлов» / ссылка на новеллу
 └─ SummariesCoordinator    Готовые пересказы → Чтение
```

- **Coordinator** владеет сценарием и создаёт ViewModel. ViewModel сообщает о переходах через замыкания
  (`onSelectBook`, `onCreate`, …) и ничего не знает о UIKit.
- **Router** оборачивает `UINavigationController`: экраны на SwiftUI встраиваются через `UIHostingController`,
  системная панель скрыта, жест «назад» работает.
- **ViewModel** — `@MainActor final class: ObservableObject` (без `@Observable`, он требует iOS 17).
- **Хранилище** — `BookRepository` (JSON в Documents) за протоколом; Core Data можно подключить без изменения экранов.

```
ShortLib/
├─ App/            AppDelegate, SceneDelegate, AppDependencies (DI)
├─ Coordinators/   Coordinator, Router, App/Library/Import/Summary
├─ Features/       Library, Import, Summary, Summaries, Profile (View + ViewModel)
├─ Domain/         Book, Chapter, Summary, SummaryPreset
├─ Services/       ZipReader, EPUBParser, WebNovelScraper, SummaryEngine, BookRepository
├─ DesignSystem/   DS (цвета, шрифт, отступы, анимации) + компоненты
└─ Resources/      Assets.xcassets, Info.plist
```

## Как работает пересказ

Есть два движка с одним протоколом `SummaryEngine`. Выбор делает `AppDependencies.makeSummaryEngine()`.

### Claude (пересказ своими словами) — если в Профиле сохранён ключ API

1. **Память сюжета.** Главы обрабатываются по порядку. В каждый запрос уходят текст главы, пересказ
   предыдущей главы и «память»: персонажи, отношения, открытые линии, факты о мире. Модель возвращает
   пересказ и обновлённую память, поэтому глава 40 понимает, кто такой персонаж из главы 3.
2. **Подробность** задаёт длину: доля от объёма главы (3–25%) и стиль («только главное» → «все значимые сцены»).
   Фокус (сюжет, персонажи, мир, цитаты) и язык пересказа передаются в системный промпт.
3. **Длинные главы** (> 8 000 слов) делятся по абзацам на части: сначала заметки по частям, потом пересказ.
4. **Связи между главами** — второй проход, только если спойлеры разрешены. Каждая глава сопоставляется
   с 2 предыдущими и 3 следующими: что подготовлено раньше, что раскроется позже.
5. **Общая сводка и персонажи.** Для больших книг сначала сводки арок по 15 глав.

Модели: главы — `claude-haiku-5-5`; сводка — `claude-sonnet-5-5` в режиме «Качество».
Промпты — `Services/LLM/Prompts.swift`, ответы в XML-тегах (`<summary>`, `<memory>`, `<links>` …).
Перед запуском экран настроек показывает оценку: число запросов и токенов.

Ключ хранится в Keychain. Чтобы перейти на подписку, поменяйте `LLMConfig.endpoint` на свой сервер:
сервер хранит ваш ключ, проверяет подписку App Store и пересылает запросы в Anthropic. Экраны менять не нужно.

### Ключевые фразы — бесплатно, офлайн, без ключа

`ExtractiveSummaryEngine` выбирает самые значимые предложения глав (NaturalLanguage).

### Загрузка книг

- **EPUB** распаковывается встроенным `ZipReader` (Apple Compression), затем `container.xml` → OPF → главы из spine.
- **Веб-новелла**: со страницы оглавления собираются ссылки на главы, тексты загружаются по одной и кешируются.
