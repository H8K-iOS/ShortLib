# ShortLib

iOS-приложение для кратких пересказов книг: EPUB-файлы и веб-новеллы по ссылке на оглавление.
Пересказ своими словами через Claude API с «памятью сюжета» и связями между главами;
без ключа — бесплатный режим «ключевые фразы».

## Правила работы
- **Общайся с пользователем только на русском.** Код, имена и коммиты — на английском, комментарии в коде — на русском.
- iOS 16+, Swift 5, SwiftUI (экраны) + UIKit (навигация). MVVM + Router / Coordinator. Без внешних зависимостей.
- Не использовать API iOS 17+ (`@Observable`, SwiftData, `MainActor.assumeIsolated` и т. п.) без `if #available`.
- Гайдлайны UI обязательны (см. `GUIDELINES.md`): лёгкие анимации только из `DS.Motion`, один шрифт только из `DS.Font`,
  цвета только из `DS.Color` / `DS.UIColorToken`. Скрипт `scripts/check-guidelines.sh` проверяет их при сборке.
- Новые `.swift`-файлы должны попасть в target `ShortLib` в `ShortLib.xcodeproj` (добавить через Xcode или правкой `project.pbxproj`).
- Не коммитить локальный `DEVELOPMENT_TEAM` в `project.pbxproj`.
- Push в `main` после `git pull --rebase`. CI (`.github/workflows/ios.yml`) запускается на push — пользователь проверяет сборку сам на Mac.

## Сборка
```bash
open ShortLib.xcodeproj          # Xcode 15+, выбрать Team, ⌘R
# или из терминала:
xcodebuild -project ShortLib.xcodeproj -scheme ShortLib \
  -destination 'platform=iOS Simulator,name=iPhone 16 Pro' CODE_SIGNING_ALLOWED=NO build
```

## Агенты (`.claude/agents/`)
Работа разделена на три направления. Делегируй задачу профильному агенту:
| Агент | Когда |
|---|---|
| `ui-designer` | экраны, компоненты, дизайн-система, анимации, тёмная тема, доступность |
| `ios-architect` | архитектура, координаторы, ViewModel, сервисы, хранение, ошибки сборки, git, CI |
| `summarization` | качество пересказа, промпты, модели, стоимость, подписка, парсинг EPUB и веб-новелл |

Контекст каждого направления — `docs/context/*.md`. Принятые решения записывай туда же
(и крупные — в раздел «Ключевые решения» ниже).

## Ключевые решения
1. Стиль интерфейса — «тёплый свет на точной структуре» (с 2026-11-13, вместо Airbnb): тёмная основа, блоки-виджеты, тонкие линии, стеклянные панели; один тёплый свет (`DS.Color.glow`) и один коралловый акцент — только у главного элемента экрана. Подробно — `docs/context/ui.md`.
2. Пересказ сейчас по ключу пользователя (BYOK, Keychain). Дальше — подписка App Store + свой сервер-прокси
   (сменить `LLMConfig.endpoint`). Ключ разработчика в приложение не встраивать.
3. Связь глав: «память сюжета» на каждом шаге + второй проход связей с будущими главами, если спойлеры разрешены.

## Статус
- Каркас, дизайн-система, импорт, оба движка пересказа — в `main`.
- Первая сборка в Xcode ещё не подтверждена: возможны мелкие ошибки компиляции.
