# ShortLib — UI

Общий контекст — `CLAUDE.md` в корне репозитория.

## Зона ответственности
Экраны, компоненты, дизайн-система, анимации, тёмная тема, доступность, лукбук. Код UI — SwiftUI в `ShortLib/Features/*/…View.swift` и `ShortLib/DesignSystem/`.

## Гайдлайны пользователя (обязательны)
1. **Лёгкие анимации**, не нагружающие ядро: только `DS.Motion` (`standard` 0.2 c, `tap` 0.12 c, `progress` 0.3 c, ease-out); анимируем opacity/scale/offset/trim; без `repeatForever`, пружин и вращающихся спиннеров; всегда `DS.Motion.respecting(_:)` (Reduce Motion).
2. **Один лаконичный шрифт** на всех экранах: SF Pro через `DS.Font` (largeTitle, title, headline, body, callout, caption, label, number, icon). Никаких `.font(.system…)` в фичах.
3. **Одна палитра**: только `DS.Color` / `DS.UIColorToken`, значения в `Assets.xcassets/Colors` (светлая + тёмная).

Скрипт `scripts/check-guidelines.sh` выдаёт warning в Xcode при нарушении. Подробно — `GUIDELINES.md`.

## Экраны
- Таб-бар: Библиотека · Добавить (открывает импорт модально) · Пересказы · Профиль
- Библиотека: поисковая плашка, вкладки категорий, карточки книг как объявления Airbnb
- Карточка книги: обложка, источник, факты, список глав, липкая нижняя панель «Пересказать / Читать»
- Импорт: EPUB или ссылка на оглавление, превью найденных глав
- Настройки пересказа (bottom sheet): движок + оценка токенов, детальность (сегменты + слайдер), фокус (чипы), спойлеры, главы
- Прогресс: кольцо, этапы, «Свернуть» (генерация продолжается)
- Чтение: вкладки Кратко / По главам / Персонажи, блоки связей между главами, «Поделиться»
- Профиль: ключ Claude API, модель, язык пересказа, детальность по умолчанию

## Решения
- 2026-11-13. Детальность показывается диапазоном слов на главу (`DetailLevel.wordRangeText`, «≈ 400–700 слов»), а не процентом:
  длину задаёт `DetailLevel.wordRange`, процент ползунка — только ориентир («≈ 12% от оригинала», мелким текстом).
  Так же в бейдже экрана прогресса: «Баланс · ≈ 400–700 слов».
- 2026-11-13. Бесплатный лимит (5 глав на устройство, один раз). Настройки пересказа знают режим `SummarySettingsViewModel.Access`:
  `ownKey` · `free(chaptersLeft)` · `limitReached` · `extractive`.
  - `free`: карточка режима + `QuotaMeter` «Бесплатные главы 3 из 5»; «Все N» заблокировано (замок), степпер до остатка,
    подсказка «Без ключа — до 3 глав…»; главная кнопка «Пересказать 3 главы».
  - `limitReached`: `NoticeCard` «Бесплатные главы закончились» с главной кнопкой «Добавить свой ключ» (`onAddKey` → Профиль),
    «Подписка появится скоро»; кнопка футера становится вторичной «Собрать ключевые фразы» (один акцент на экран).
  - `extractive`: честная подпись «Это выдержки из текста, а не пересказ…» и ссылка «Добавить ключ».
  - Профиль: группа «Бесплатный пересказ» с `QuotaMeter`, остаток обновляется при открытии.
  - Ошибки сервера показываются как есть в карточке ошибки экрана прогресса.
- Новые компоненты: `QuotaMeter`, `RussianPlural` (ProgressRing.swift), `NoticeCard` (FlowLayout.swift) —
  `NoticeCard` использовать и для будущих пустых состояний/ошибок.
- 2026-11-13. Чтение во время пересказа (решение пользователя: читать можно с первой готовой главы).
  - Прогресс: под кольцом «Примерно N мин» (`WaitTimeText`, оценка — `SummaryJob.estimatedRemaining`) и «Готово X из N глав»;
    карточка «Главы 1–8 готовы»; в футере главная кнопка «Начать читать» вместо «Свернуть» (свернуть — стрелкой вверху).
  - Читалка: бейдж «8 из 33 · ≈ 12 мин»; готовые главы из `Book.partialSummary` появляются сами (opacity 0.2 с);
    под ними плашка «Глава N готовится…» с полоской, а если пересказ остановлен — «Продолжить пересказ».
    «Кратко» до конца — `NoticeCard` «Сводка будет готова после всех глав» + «Читать по главам»; персонажи скрыты до конца.
  - Карточка книги: пересказ идёт → «Читать готовое» + главная «Открыть прогресс»; остановлен → «Читать готовое» +
    «Продолжить пересказ»; в фактах «Пересказываем / Пересказ остановлен · готово 12 из 33 глав».
  - Библиотека: бейдж на обложке «Пересказываем · 12 из 33» (с песочными часами) или «Готово 12 из 33» у остановленного.
- 2026-11-13. Читалка: порядок вкладок «По главам · Персонажи · Кратко». При открытии «Кратко» текст сводки размыт (blur 9, без анимации blur),
  поверх — `SpoilerGate`: весь экран под `.ultraThinMaterial`, по центру полупрозрачная карточка (`.regularMaterial`, Radius.xl)
  «Краткое содержание всей книги» + «Показать сводку» / «Читать по главам»; тап мимо — назад к главам. Согласие живёт, пока открыта читалка.
- 2026-11-13. «По главам» — раскрывающиеся карточки (`ChapterCard`): свёрнуто — «Глава N · ≈ M мин» + название + шеврон;
  раскрыто — линия, текст главы цветом `DS.Color.inkSoft` (новый токен InkSoft: #444444 / #D4D4D4 — на тон спокойнее заголовков),
  связи и «Дальше: глава N+1» (сворачивает текущую, раскрывает и прокручивает к следующей). Над списком «Раскрыть все / Свернуть все».
  Раскрытие без анимации высоты (только opacity и поворот шеврона).

## Стиль «Тёплый свет на точной структуре» (решено 2026-11-13, заменяет Airbnb)
Референсы пользователя: Phenomenon Studio — Effortless Technologies (тёплый свет на холодной структуре, стекло) и Zest (тёмная тема, блоки-виджеты, яркие акценты).
- Тёмная основа (Background #0B0B0C, Surface #151517, Card #18181B, Line #26262A); светлая тема сохраняется.
- Тёплый свет: GlowWarm #FF6B3D / #FF8A5C, GlowSoft #F79A6B / #FFB07A; `DS.Color.glow(radius:)`, `DS.Color.progressArc`.
- Подписи — мелкие заглавные с разрядкой, крупные цифры; стеклянные шапки и нижнее меню; главный экран — блоки-виджеты.
- Без «глитча» в заголовках и без подвижного свечения (гайдлайн лёгких анимаций).
- Экран прогресса (первый в новом стиле): кольцо 180 pt, линия 16 pt, тёплая дуга и свечение; кольцо можно потянуть (`dsElasticDrag`);
  крупно «Примерно N мин»; блик по «Начать читать» при появлении и с каждой новой главой.
- Дальше: библиотека-виджеты (нужен прогресс чтения от ios-architect), читалка со стеклянной шапкой, остальные экраны.
