# ShortLib — пересказ

Общий контекст — `CLAUDE.md` в корне репозитория.

## Зона ответственности
Качество пересказа, промпты, модели, подробность, связи между главами, стоимость, переход на подписку, парсинг EPUB и веб-новелл.

## Чего хочет пользователь
Не вырезать куски текста, а **анализировать главу и пересказывать своими словами**, с длиной по выбранной подробности, и **сопоставлять с предыдущими и следующими главами**.

## Два движка (`SummaryEngine`)
Выбор — `AppDependencies.makeSummaryEngine()`: есть ключ API → `LLMSummaryEngine`, нет → `ExtractiveSummaryEngine`.

### LLMSummaryEngine (`Services/LLM/LLMSummaryEngine.swift`)
1. Главы по порядку. В каждый запрос: текст главы + пересказ предыдущей + **память сюжета** (персонажи, отношения, открытые линии, факты мира, ≤350 слов). Ответ: `<analysis>` (скрытый разбор, ≤120 слов, не показывается) + `<summary>` + `<memory>`.
2. Длина главы — `SummaryPreset.targetWords`: `слова_главы × ratio`, зажатое в диапазон уровня (`DetailLevel.wordRange`), но не больше 35% главы и не меньше 40 слов; стиль по `DetailLevel`.
3. Глава > 8 000 слов → части по абзацам → `<notes>` → пересказ из заметок.
4. Спойлеры разрешены → второй проход: глава + 2 предыдущих + 3 следующих → `<links>` (1–3 предложения или «нет»), параллельно по 3 запроса.
5. Сводка: если пересказов > 12 000 слов — арки по 15 глав (`<arc>`), затем `<overview>` + `<characters>` («Имя — описание»).

- Промпты — `Services/LLM/Prompts.swift`, разбор — `TagParser`.
- Модели: главы `claude-haiku-5-5`; сводка `claude-sonnet-5-5` в режиме «Качество», Haiku в режиме «Быстро».
- `AnthropicClient`: Messages API, `anthropic-version: 2023-06-01`, ретраи на 429/5xx/529 (2, 4, 8, 16 c, retry-after), понятные ошибки на русском.
- Оценка запросов и токенов — `SummaryCostEstimate`, показывается в настройках.

### ExtractiveSummaryEngine (`Services/SummaryEngine.swift`)
Бесплатно, офлайн: NLTokenizer, частотные веса, бонусы за первое предложение, имена (NLTagger), цитаты.

## Требования к пересказу (решения с пользователем, 2026-11-13)
Эталон — пример пользователя по гл. 1 «Мастера и Маргариты»: связный пересказ своими словами, а не выборка фрагментов.
Опора на 7 критериев: понимание (причины, подтекст), выделение главного, структура (начало → развитие → завершение),
анализ (почему и к чему ведёт), сжатие без потери смысла, грамотность без повторов, сохранение замысла автора.
- **Настоящее время**, третье лицо (можно пересмотреть позже).
- **Интонация автора** сохраняется (ирония, сатира, напряжение), но без копирования предложений.
- **Абзац о значении главы** — только на уровне «Подробно»; без штампа «Таким образом…».
- Перед пересказом модель пишет скрытый разбор `<analysis>` (главное/второстепенное, причины-следствия, идея, тон, концовка). +≈400 токенов выхода на главу.
- **Модель глав остаётся Haiku** (дешевле); Sonnet для глав — вернуться к вопросу позже.
- **Длина главы** (слов): Кратко 200–400 (по умолчанию 6%), Баланс 400–700 (12%), Подробно 700–900 (20%).
  Ползунок двигает длину внутри диапазона; потолок 35% главы, чтобы короткие главы веб-новелл сжимались.
  Пример пользователя (≈900 слов на ≈4 000) — это «Подробно», допустимо короче.
- Процесс: любые изменения промптов сначала предлагать и обсуждать, потом внедрять.

## Ключ и монетизация
- Сейчас **BYOK**: пользователь вводит ключ Claude API в Профиле → проверка коротким запросом → Keychain.
- План: **подписка App Store (StoreKit 2) + свой сервер-прокси**. Ключ разработчика только на сервере. Сервер проверяет подписку (App Store Server API), ведёт лимиты, пересылает в Anthropic. В приложении — сменить `LLMConfig.endpoint` и авторизацию.
- Посчитать себестоимость книги до выбора цены подписки.

## Загрузка текста
- EPUB: `ZipReader` (Apple Compression, deflate) → `container.xml` → OPF (manifest/spine) → XHTML → `HTMLText.plainText`. Главы < 40 слов пропускаются.
  - Служебные страницы пропускаются (`EPUBParser.isServicePage`): nav EPUB 3, `<guide>` toc/cover/title-page/copyright;
    заголовок «Аннотация / Содержание / Annotation / Примечания…»; ≥50% абзацев — строки «Глава N»; >50% слов — ссылки.
  - Название главы без номера: «Глава 1» + «Никогда не разговаривайте…» → «Никогда не разговаривайте…»
    (номер показывает UI); строки «Часть …» над главой отбрасываются. Без названия — заголовок как есть.
  - Уже импортированные книги нужно импортировать заново.
- Веб-новеллы: `WebNovelScraper` ищет на оглавлении ссылки со словами chapter/глава/ch-N; текст главы — самые длинные `<p>`. Тексты грузятся по одной во время пересказа и кешируются. Для конкретных сайтов могут понадобиться свои правила.

## Открытые вопросы
- Новый промпт главы ещё не прогнан на реальной главе — сравнить с эталоном пользователя
- Экстрактивный движок по-прежнему режет по доле `ratio`, без диапазонов слов
- Флаг «Без спойлеров» для экстрактивного движка ничего не меняет
- Кеш пересказов глав при смене подробности (сейчас пересказ делается заново)
- Пересказ свежих глав онгоинг-новеллы без полного перезапуска
- Себестоимость и лимиты подписки
